不同获保人数下的行为

25V 的组别来自第 16 轮自主购买，存在自选择；25F 来自环境分配，获保率不是购买意愿。前期数据也按第 16 轮的选择/分配追溯分组。“0 人”没有数据时显示缺失，不能当作 0 转账。25F 的概率来自本批运行配置，论文概率仍未确认。

搭档上次怎样做，自己这次怎样做

对每次发送者机会，寻找此前最近一次搭档作为发送者的已结算选择。区分尚无历史、搭档上次转 0、搭档上次转正数；先在 Agent 的各类机会内平均，再等权汇总，区间按场次聚类。此关联同时受人格、阶段和历史选择影响，不能单独识别互惠动机或记忆的因果作用。

实验在哪一轮自然结束

每场在前 47 轮继续进行。进入第 48 或 49 轮后，该轮结束的设定概率为 78%。仍进入第 50 轮的场次全部结束。
